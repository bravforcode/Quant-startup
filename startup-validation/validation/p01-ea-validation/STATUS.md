## สิ่งที่ผู้ก่อตั้งต้องทำเอง (เรียงตามลำดับ)

1. ลงชื่อใน `preregistration.md` และยืนยันว่า `a6d4c79` คือ commit ที่ล็อก
2. สร้างโปรเจกต์ Neon (ฟรี) แล้วรัน `sql/apply.sh` และ `sql/test_schema.sh` ด้วย `DATABASE_URL` ของคุณบนเครื่องของคุณ (ไม่ต้องส่ง connection string ในแชต)
3. ตัดสินว่าจะเปิดโดเมน reddit.com, mql5.com และ pantip.com ให้อ่านต่อหรือไม่ (Allowed domains)
4. ยืนยันว่าการไม่รอทนายยังรวมถึงการรับเงินหรือไม่ ถ้าใช่ ต้องเพิ่มหัวข้อที่ลงวันใน `preregistration.md` (D7)
5. ส่งจดหมายถึงทนายเอง หรือบอกชื่อทนาย แล้วผมจะเตรียมอีเมลให้พร้อมส่ง
6. กรอก Mode Calendar (§5)
7. หาผู้ให้สัมภาษณ์ที่ตรงกับ segment ด้วยช่องทางที่ผู้ก่อตั้งอนุมัติ (ไม่ใช่ DM ที่ส่งโดย automation)

## สิ่งที่ยังไม่มีคำตอบจากผมและต้องมีคำตอบจากคุณ

- Neon `apply.sh` ยังไม่เคยรันบน Neon จริง (ทดสอบแล้วบน PostgreSQL 16.15) ถ้าล้มเหลวที่การสร้าง role ให้ส่งข้อความ error มา
- Landing page ยังไม่มี endpoint: Neon ไม่มี REST ในตัว ต้องเลือกว่าจะทำ function เล็ก ๆ หรือใช้บริการอื่น
