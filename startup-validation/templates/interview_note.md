# Interview note (playbook 3.3)

## 3.3 Interview Note Template
```markdown
## Interview #__ — [นามแฝง] ([อาชีพ], [ช่องทาง], [วันที่])
- ความถี่ของปัญหา: ทุกวัน/สัปดาห์/เดือน
- Workaround ปัจจุบัน:
- ต้นทุนที่เสียไป: ___ ชม./สัปดาห์ หรือ ___ บาท/เดือน
- เคยจ่ายค่าอะไรมาก่อน: (tool/คน/คอร์ส + ราคาถ้าจำได้)
- Pain score: __/10 (พร้อมเหตุผลที่เขาให้)
- Quote สำคัญ (คำพูดเป๊ะ ๆ): "..."
- ประเภทข้อมูล: FACT (พฤติกรรม) / FACT (เงิน) / OPINION / POLITENESS
- Referral ที่ได้: [ชื่อ/กลุ่ม]
- สัญญาณพิเศษ: ถามกลับว่า "เอาเมื่อไหร่" หรือไม่?
```
